# AI 입력 프롬프트

[도메인 맥락]
나는 웹 퍼블리셔 7년, 프론트엔드 4년차 개발자이고 코드 리뷰 방식을 간소화하고 싶다

[네 동작 분석]
1. 분해:
- 코드 컨벤션을 기능 단위로 데이터를 분리
- 디자인 시스템에 어긋나는 케이스 감지
- 시맨틱 에러와 같은 코드 단위 오류 감지
- PR에 포함된 주석 혹은 문의사항 감지
- 빠른 피드백을 위한 보조 리뷰어 에이전트 필요
2. 패턴:
- 해당 PR의 목적(기능 추가, 오류 수정, 단순 수정)을 PR의 분량 기준으로 패턴 감지
- AI와 사용자의 스코프 영역을 어떻게 나누면 좋을지 파악
3. 추상화: 평균 PR 리뷰에 소요되는 시간 70% 감소시키기
4. 알고리즘: PR 감지 → AI 자동화 영역 (내부 컨벤션 준수 여부 검토 → 디자인 시스템 컨벤션 준수 여부 검토 → 빌드 전 테스트 및 검사 도구 P/F 감지) → PR 중 신경써야 하는 부분 감지 → PR 제목과 작업 분량 분석 → 목적 및 주요 콘텍스트 노티 → 에이전트가 자체 처리한 내역 요약 포함하여 검토사항 출력
